# Koordináta-labor

Interaktív, magyar nyelvű Descartes-koordináta átváltó polár-, henger- és gömbi koordinátákhoz. A Descartes-féle `x`, `y`, `z` bemenetből bármely két koordinátarendszer összehasonlítható. A polár rendszer 2D ábrán, a térbeli rendszerek külön-külön forgatható és alaphelyzetbe állítható 3D ábrán jelennek meg.

## Használat

Nyisd meg az `index.html` fájlt, vagy szolgáld ki a mappát bármely statikus webszerverrel.

## GitHub Pages

1. Töltsd fel a fájlokat egy GitHub repository alapkönyvtárába.
2. A repository **Settings → Pages** menüjében válaszd a **Deploy from a branch** lehetőséget.
3. Forrásként add meg a `main` ágat és a `/ (root)` mappát.

Az alkalmazás nem igényel buildet vagy szerveroldali komponenst.
